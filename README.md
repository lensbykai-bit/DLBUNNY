# DLBunny Personal

Personal-use Android WebView app for https://dlbunny.com/. Download only media you own or are permitted to download.

## APK build
Open GitHub Actions > Build DLBunny Personal APK > Run workflow. Once successful, download the `DLBunnyPersonal-debug-APK` artifact and extract `app-debug.apk`.

The app needs an Internet connection, and downloads depend on website compatibility. This project is not affiliated with DLBunny.
